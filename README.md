# AlexPG – Portfolio

Este repositorio contiene mi portfolio personal como diseñador web, diseñador gráfico y creador de proyectos digitales.  
Aquí muestro mis trabajos, proyectos y contenido visual.

Puedes visitar la web en:  
https://alexpg-design.github.io/alexpg-portfolio/

## Tecnologías

- HTML, CSS y JavaScript sin frameworks
- Diseño responsive y navbar con menú hamburguesa
- Animaciones con Intersection Observer
- Imágenes optimizadas en formato WebP

## Estructura del proyecto

- `index.html` – Página principal
- `projects.html` – Proyectos web
- `designs.html` – Galería de diseños
- `about.html` – Sobre mí
- `contact.html` – Contacto
